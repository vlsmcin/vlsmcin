# Hi 👋, I'm Vinícius Lima Sá de Melo

### Computer Engineering Student at UFPE | AI Engineering & Machine Learning

I'm a Computer Engineering student at the Federal University of Pernambuco (UFPE), interested in building intelligent systems by combining **Machine Learning, AI agents, and Software Engineering**.

Currently, I'm working at **CIn–Motorola**, developing software for an internal AI platform, integrating AI agents and tools through the Model Context Protocol (MCP).

My background also includes applied research in **Natural Language Processing, Computer Vision, and 4G/5G networks**, with a scientific publication in IEEE.

### 🔬 Areas of Interest

- **Machine Learning:** Model development, evaluation, and experimentation.
- **Natural Language Processing:** Text classification and NLP pipelines.
- **Computer Vision:** Deep learning, object detection, and image processing.
- **Software Engineering:** Full-stack development, APIs, and scalable systems.

### 🚀 Featured Projects

#### 📰 [Fake News Detection](https://github.com/vlsmcin/ligia-challenge-NLP-vlsm)
Natural Language Processing pipeline for fake news classification using Python, Scikit-learn, and word- and character-level TF-IDF features. The project explores model selection and evaluation, achieving a reported F1-score above 99% on the test set.

#### 📦 [Industrial Package Defect Detection](https://github.com/Davi-SB/Deep-Learning-Package-Inspection)
Computer vision project using transfer learning with EfficientNetB0 to classify package defects, achieving a reported accuracy of 90%.

#### 🤖 Computer Vision for Robotics
Applied research project developed through FACEPE in partnership with Accenture, involving backpack detection with YOLOv8 and fisheye distortion correction for a Unitree Go1 quadruped robot. The solution achieved a 3.5× performance improvement over the previous version.
